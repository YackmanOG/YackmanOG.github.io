Privacy Policy

Auto Clipper · Effective November 13, 2026

Auto Clipper is a private tool that uploads the owner's own Shorts to the owner's own YouTube channels. It runs only on the owner's computer and is used only with the owner's own Google accounts.

Google data the app accesses

  • Upload videos (https://www.googleapis.com/auth/youtube.upload): to publish Shorts to the connected channel.
  • Read the channel name (https://www.googleapis.com/auth/youtube.readonly): to show which channel is connected. No other account data is read.

How it's stored

The sign-in tokens Google issues are saved only as local files on the owner's computer. They are not uploaded to any server run by the app, because the app has none.

Sharing

The app does not sell, share, or transfer Google user data to anyone. It does not use Google user data for advertising, and it does not use it to train AI models.

Limited Use

Auto Clipper's use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

YouTube

Auto Clipper uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token files removes all stored data.
